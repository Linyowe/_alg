# 計算 $2^n$ 的多種實作方法與效能分析

本專案比較了計算 $2^n$（在 $n = 100$ 的條件下）四種不同寫法的程式碼邏輯與執行效率。

---

## 📋 程式方法介紹

### 1. 方法 1：內建運算子 (`2**n`)
* **程式碼**：`return 2**n`
* **原理**：直接利用 Python 底層最佳化的運算子進行計算。
* **時間複雜度**：$O(1)$ 或 $O(\log n)$（取決於硬體層級的整數運算實作）。
* **執行狀況**：**極快**。瞬間完成，是實際開發中最推薦的做法。

### 2. 方法 2a：二元遞迴 (`power2n(n-1) + power2n(n-1)`)
* **程式碼**：
  ```python
  if n == 0:
      return 1
  return power2n_2a(n - 1) + power2n_2a(n - 1)
  ```
* **原理**：將問題拆解成兩個相同的子問題相加。
* **時間複雜度**：$O(2^n)$（指數級成長）。
* **執行狀況**：**跑不出來**。當 $n = 100$ 時，呼叫次數會高達 $2^{100}$ 次，導致計算量過大而無限卡死。

### 3. 方法 2b：線性遞迴 (`2 * power2n(n-1)`)
* **程式碼**：
  ```python
  if n == 0:
      return 1
  return 2 * power2n_2b(n - 1)
  ```
* **原理**：每次遞迴只呼叫一次自身並乘上 2。
* **時間複雜度**：$O(n)$。
* **執行狀況**：**很快**。遞迴深度為 100 層，能輕鬆在瞬間完成。

### 4. 方法 3：遞迴 + 查表 (Memoization / 記憶化搜尋)
* **程式碼**：
  ```python
  memo = {0: 1}
  def power2n_3(n):
      if n in memo:
          return memo[n]
      memo[n] = power2n_3(n - 1) + power2n_3(n - 1)
      return memo[n]
  ```
* **原理**：結合動態規劃的精神，利用字典 (`memo`) 記錄已經計算過的結果。當再次遇到相同的 $n$ 時直接回傳，避免重複運算。
* **時間複雜度**：第一次計算為 $O(n)$，後續重複查詢可達 $O(1)$。
* **執行狀況**：**極快**。有效解決了純遞迴可能帶來的重複計算問題。

## 📊 效能比較表（$n = 100$）

| 方法 | 核心邏輯 | 時間複雜度 | 執行結果 | 備註 |
| :--- | :--- | :--- | :--- | :--- |
| **方法 1** | `2**n` | $O(1)$ | 完美執行 ($\approx 0$ 秒) | 最快、最直接 |
| **方法 2a** | `power2n(n-1) + power2n(n-1)` | $O(2^n)$ | **無法跑出結果** | 指數爆炸，會直接卡死 |
| **方法 2b** | `2 * power2n(n-1)` | $O(n)$ | 完美執行 ($\approx 0$ 秒) | 線性遞迴，表現良好 |
| **方法 3** | 遞迴 + 查表 (`memo`) | $O(n)$ | 完美執行 ($\approx 0$ 秒) | 適合需要重複呼叫、保留中間狀態的場景 |
